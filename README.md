# Revenue Analytics Platform (Tableau)

A Tableau analytics project over a revenue dataset of **$3.5M+** across **1,000 orders**.

## Overview

Analyzed where revenue comes from and how it moves over time: temporal trends, product performance and customer segmentation, packaged into interactive Tableau dashboards.

## Tech

- Tableau
- Data preparation and modeling

## What the analysis covers

- **Temporal trends**: how revenue evolves over time
- **Product performance**: which products drive the $3.5M+ in revenue
- **Customer segmentation**: which customer groups matter most, across 1,000 orders
